# Liquid Glass Presentation

Шаблон презентації на 20 слайдів у світлій монохромній темі (відтінки сірого): живий WebGL-фон (срібний туман, скляне кільце, лінія-хвиля), Liquid Glass-панелі, типографіка в стилі Apple та анімації появи елементів.

Темна версія — коміт `038a8de`, світла з бірюзовими акцентами — `b913bf2`.

## Керування

| Дія | Клавіші |
|---|---|
| Наступний / попередній слайд | `→` `←`, `Space`, колесо миші, свайп |
| Перший / останній | `Home` / `End` |
| Огляд усіх слайдів | `G` |
| Повний екран | `F` |
| Відкрити конкретний слайд | `index.html#7` |

## Як редагувати

Усі слайди лежать в `index.html`, кожен у своєму `<section class="slide">`.

- `data-scene="…"` — сцена фону для слайда: `hero`, `calm`, `ring`, `quote`, `wave`, `corner`, `low`, `arc`, `glow`, `horizon`, `deep`, `sweep`, `final` (параметри в `js/bg.js`).
- `data-title="…"` — назва слайда в огляді (`G`).
- `data-a` — елемент з'являється з анімацією. Варіанти: `blur`, `left`, `right`, `scale`, `pop`, `fade`.
- `data-split` — заголовок з'являється по словах; `data-split="blur"` — слова проявляються з розмиття.
- `<em class="hl">…</em>` — бірюзове виділення слова з переливом.
- `data-count="98"` — число, яке «набігає» під час появи слайда (`data-dec="1"` — один знак після коми).
- `class="glass"` — панель Liquid Glass.
- `.ph` — плейсхолдер для фото. Заміни його на `<img src="img/photo.jpg" style="width:100%;height:100%;object-fit:cover">`.

Сцена має розмір 1920×1080 і масштабується під будь-який екран.
